# Download minimega

## Current release

minimega releases are published on
[GitHub Releases](https://github.com/sandia-minimega/minimega/releases).
The [latest release](https://github.com/sandia-minimega/minimega/releases/latest)
provides release notes and downloadable assets:

- An AMD64 Debian package (`.deb`)
- An x86-64 RPM package (`.rpm`)
- A prebuilt binaries archive (`-binaries.tar.gz`)
- A Python wheel (`.whl`)
- Source archives generated by GitHub

Choose the package for your Linux distribution or use the binaries archive.
See the [installation guide](installing.md) for package, archive, source, and
Docker instructions.

## Previous GitHub releases

Older supported releases and their assets remain available from the
[GitHub Releases list](https://github.com/sandia-minimega/minimega/releases).

## Legacy downloads
