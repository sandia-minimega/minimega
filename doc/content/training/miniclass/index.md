# Historical miniclass

This self-paced miniclass was recovered from the former Sandia minimega
website. It is separate from the newer [Mini101 course](../module01.md).

The lessons are preserved as historical training material. Many examples
target old minimega releases and older Ubuntu, QEMU, VirtualBox, VMware,
Python, or third-party tools. Prefer current guides and generated API help
when the material conflicts.

Module 24 was linked by the legacy index but returned HTTP 404. Modules 47
and 48 did not appear in that index.
