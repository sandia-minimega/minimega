minimega Python bindings
========================

`minimega` is the Python client package for controlling a running minimega
instance over its UNIX domain socket. The bindings are autogenerated from
minimega's command definitions and expose command docstrings directly in Python.

These bindings do not start minimega for you. You must already have a running
minimega instance and permission to access its command socket.

## Requirements

- Python 3.10 or newer
- A running minimega instance
- Access to the minimega command socket, which defaults to:

  `/tmp/minimega/minimega`

By default, that socket is often only readable/writable by root.

## Install

```bash
pip install minimega
```

## Quick start

```python
import minimega

with minimega.connect() as mm:
    for resp in mm.version():
        print(resp["Response"])
```

To print tabular command output:

```python
import minimega

with minimega.connect() as mm:
    minimega.print_rows(mm.vm_info())
```

To scope commands to a namespace:

```python
import minimega

with minimega.connect() as mm:
    with mm.namespace("lab") as ns:
        ns.vm_info()
```

## Response model

Use `close()` or a `with minimega.connect() as mm:` block to close the UNIX
socket when the client is no longer needed.

One connection is serial: all responses from one command must be consumed
before another command is issued on the same connection. If a command produces
additional responses, consume them with `streamResponses()` or discard them with
`minimega.discard(...)`.

Create one connection per process. Do not pickle a connected client or share it
across `multiprocessing` workers.

Use `cc_filtered(...)` to scope command-and-control filters and automatically
clear the filter on exit:

```python
with minimega.connect() as mm:
    with mm.cc_filtered("uuid=abc"):
        mm.cc_exec_once("pkill iperf3")
```
